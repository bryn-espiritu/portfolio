# Bryn Espiritu — Personal Portfolio

A responsive personal portfolio website showcasing my professional background, email marketing experience, technical skills, certifications, and education.

## About

I'm an Email Campaign Specialist with experience in email campaign execution, HTML/CSS email development, A/B testing, campaign scheduling, and customer support. This portfolio provides an overview of my experience and skills, with links to selected certifications and professional profiles.

## Features

- **Professional introduction** — profile, summary, and contact links.
- **Core skills and platforms** — Klaviyo, Attentive, HTML/CSS, campaign scheduling, A/B testing, and customer support.
- **Work experience** — professional experience and responsibilities.
- **Certifications directory** — filter certificates by category:
  - Klaviyo & Email
  - Development & Web
  - Technical & IT
- **Education** — academic background.
- **Responsive layout** — built with Bootstrap 5.3 for desktop and mobile screens.

## Built With

- HTML5
- CSS3
- JavaScript
- [Bootstrap 5.3](https://getbootstrap.com/)
- [Font Awesome 6](https://fontawesome.com/)

Bootstrap and Font Awesome are loaded through their CDN links in `index.html`.

## Run Locally

This is a static website and does not require a package manager, build process, or backend server.

1. Clone the repository:

   ```bash
   git clone https://github.com/bryn-espiritu/portfolio.git
   ```

2. Open the project folder:

   ```bash
   cd portfolio
   ```

3. Open `index.html` in your web browser.

   Alternatively, use the **Live Server** extension in Visual Studio Code for local preview.

## Deployment

The site can be hosted using GitHub Pages:

1. Open the repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose the `main` branch and the `/ (root)` folder.
5. Save the settings and wait for GitHub Pages to publish the site.
